01. About me

I like hard problems. When something breaks or doesn't add up, I keep reading the code and tracing the data until I can explain the root cause, not only the symptom. That habit has shaped how I build things: I start by understanding the system, then design, then write code.

Over four years I've gone from building scoring systems and real-time services at SecPod, to leading its cloud-security backend team, to co-founding Avalon, where I own the platform's backend architecture and infrastructure.

How I build today

  1. Design first: architecture, data model, API contracts and failure modes, worked out before any code.
  2. Precise specs: I turn the design into tightly scoped prompts for Claude Code, so the code it writes needs fewer fixes.
  3. Review everything: every change gets read, tested and questioned before it merges.

AI handles the typing. I'm still responsible for the design and for whether the code is correct.
